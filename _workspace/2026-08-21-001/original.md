# 제출 문안 초안

## 프로젝트 이름

짐로그

## 프로젝트 설명

60초 촬영으로 이삿짐 초안을 만들고, 고객·이사업체·현장기사가 작업 범위와 당일 변경을 같은 기록으로 확인하는 서비스

## 서비스 소개 및 문제 정의

짐로그는 서울·수도권에서 원룸이나 투룸 규모의 비대면 이사를 준비하는 20~30대 1인 가구를 위한 작업 범위 공동확인 서비스입니다. 방문 견적 없이 전화, 메신저, 사진으로 견적을 받으면 짐 목록과 작업 조건, 포함 범위, 금액이 여러 대화에 흩어집니다. 상담한 업체 담당자와 실제 현장기사가 서로 다른 내용을 전달받는 일도 생깁니다. 소비자는 이사 당일 빠진 짐이나 추가 작업을 발견해도 그것이 최초 견적의 누락인지, 현장에서 새로 생긴 변경인지 확인하기 어렵습니다.

한국소비자원에 따르면 2025년 이사서비스 피해구제는 961건이었고, 피해 유형 중 추가비용 요구가 24.9%를 차지했습니다. 소규모 이사 계약 241건에서는 20~30대의 비중이 65.1%였습니다. 짐로그는 가격의 적정성을 판정하거나 분쟁의 책임을 정하지 않습니다. 대신 고객, 업체, 현장기사가 같은 작업 범위와 금액을 확인하고, 당일 변경은 최초 승인본과 분리하여 다시 동의받도록 돕습니다.

## 핵심 기능 및 해결 방식

고객이 방을 약 60초 촬영하면 Vertex AI의 Gemini가 영상에서 가구, 가전, 박스와 확인이 필요한 현장 조건을 찾아 수정 가능한 초안으로 정리합니다. AI가 가격이나 차량, 인원을 자동으로 결정하지 않으며, 고객이 수량과 누락을 검수한 뒤 업체에 전달합니다.

업체는 같은 짐 목록을 보면서 포함·제외 작업, 기본금액, 조정 사유와 총액을 제안합니다. 고객과 업체가 동일한 버전을 각각 확인해야 승인본이 되며, 승인된 버전은 덮어쓰지 않고 잠깁니다. 현장기사는 작업 전에 최신 승인본만 열람합니다. 실제 현장이 다르면 기사는 사진과 사실을 보고하고 금액은 입력하지 않습니다. 업체가 변경 작업과 금액을 제안하면 고객이 변경 전후 총액을 비교해 승인, 거절, 설명 요청 중 하나로 답합니다. 승인된 변경만 새 버전에 반영됩니다.

React 기반 모바일·데스크톱 화면과 FastAPI 백엔드로 세 역할의 흐름을 연결했습니다. 작업 범위 버전, 역할별 접근, 비공개 미디어, 현장 변경과 감사 이력을 서버에서 일관되게 관리합니다.

## 시장성 및 실행 전략

사진이나 영상으로 견적을 받는 서비스는 이미 존재하지만, 대부분 업체 탐색과 견적 비교에 집중합니다. 짐로그는 업체를 선택한 이후 고객, 상담 담당자, 현장기사가 같은 승인본을 보고 변경 내역까지 이어서 관리하는 구간을 다룹니다. 초기 사용자는 서울·수도권의 원룸·투룸 이사를 비대면으로 준비하는 20~30대 1인 가구입니다. 구매 고객은 반복 상담, 현장 재협상, 작업 중단과 사후 민원 비용을 줄이려는 소형 이사업체로 설정했습니다.

소비자는 무료로 참여하고, 이사업체에는 건별 이용료 또는 월 구독형 거래 관리 기능을 제공하는 모델을 우선 검증합니다. 먼저 같은 가상 이사 시나리오로 소비자 5명, 업체 상담자 5명, 현장기사 2명 이상의 역할별 사용성 테스트를 진행합니다. AI 초안과 수동 입력의 작성 시간과 치명적 누락을 비교하고, 동일 버전 공동확인 완료율 80% 이상과 버전·금액 오인 0건을 확인합니다. 이후 실제 상담 건에 적용할 조건부 유료 파일럿 3곳 또는 실제 유료 파일럿 1곳을 확보하는 것이 다음 목표입니다. 소형 업체에서 흐름을 검증한 뒤에는 이사 플랫폼의 견적·배정 과정과 연동하여 확장합니다.

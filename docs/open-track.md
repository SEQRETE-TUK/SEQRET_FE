# Open Track 요구사항 정리

이 문서는 2026 멋사대학 중앙 해커톤의 공식 트랙 안내와 심사·제출 기준을 바탕으로 Open Track 준비에 필요한 내용을 정리한다.

## 1. 트랙 주제

> **명확한 타깃 고객과 그들이 실제로 겪는 문제에서 출발해 이를 AI로 해결하는 프로덕트를 개발해 주세요.**

Open Track은 산업 분야에 제한이 없는 자유 주제다. 다만 다음 세 가지는 분명하게 제시해야 한다.

- 어느 지역에서 누가 서비스를 사용하는가
- 해당 고객이 실제로 겪는 문제는 무엇인가
- AI가 그 문제를 어떻게 해결하는가

고객을 단순히 “대학생”, “직장인”, “소상공인”처럼 넓게 정의하기보다 사용 지역과 상황, 역할이 드러나도록 구체화한다. 온라인 또는 전국 단위 서비스라면 지역 제한이 없는 이유와 실제 사용 상황을 설명한다.

### Open Track 적합성

| 평가 항목 | 배점 | 공식 기준 |
| --- | ---: | --- |
| 고객 구체성 | 10점 | 어느 지역에서 누가 서비스를 사용할지 실제 인물이 그려질 만큼 구체적으로 특정했는가 |
| 지불 의사 검증 | 10점 | 인터뷰, 시장조사 등 실제 고객 접점을 통해 돈을 낼 이유를 확인하거나 검증했는가 |

AI는 모든 프로덕트의 필수 조건이다. 별도의 기능으로 덧붙이기보다 핵심 문제를 해결하는 과정에서 AI의 역할이 드러나야 한다.

## 3. 준비해야 할 내용

### 고객과 문제

- 실제 사용자가 누구인지 지역, 역할, 사용 상황을 포함해 정의한다.
- 고객이 언제 어떤 문제를 겪는지 구체적인 사례로 설명한다.
- 현재 사용 중인 해결 방법과 그 한계를 확인한다.

### 지불 의사

- 인터뷰나 고객 접점이 포함된 시장조사를 진행한다.
- 단순한 호감보다 고객이 왜 비용을 부담할 수 있는지를 확인한다.
- 가격에 대한 반응, 도입 조건, 구매 결정 주체와 거절 이유를 함께 기록한다.

### 프로덕트와 AI

- 고객의 문제가 AI 기능을 통해 해결되는 핵심 흐름을 구현한다.
- 시연 영상과 배포 URL에서 같은 핵심 흐름이 실제로 작동해야 한다.
- 기획안, 시연 영상, IR 자료에서 고객·문제·해결 방식에 대한 설명을 일치시킨다.

## 4. 제출 항목

Open Track도 공통 제출 기준을 따른다.

| 제출물 | 주요 조건 |
| --- | --- |
| 서비스 기획안 | 아래 3개 항목을 각각 공백 포함 1,500자 이내로 작성 |
| 시연 영상 | MP4, 최대 70MB, 100초 이내 |
| IR Deck | PDF, 최대 30MB, 16:9 |
| 배포 완료 프로덕트 URL | 행사 종료까지 작동 유지 |
| GitHub | 프론트엔드·백엔드 저장소를 Public으로 유지 |
| 테스트 계정 | 로그인이 반드시 필요한 경우 제출 |

서비스 기획안에는 다음 항목이 반드시 포함되어야 한다.

1. 서비스 소개 및 문제 정의
2. 핵심 기능 및 해결 방식
3. 시장성 및 실행 전략

로그인 기능은 최소화하는 것이 권장된다. 로그인이 필요하면 심사에 사용할 테스트 계정 정보를 함께 제출한다.

## 5. 발표 유의사항

- 트랙 피칭과 본선에서 동일한 IR Deck을 사용한다.
- 대본은 흐름을 확인하는 용도로만 사용한다. 대본을 그대로 읽으면 전달력 항목이 0점 처리된다.
- 발표 시간은 엄격하게 관리되며 초과하면 발표가 중단될 수 있다.
- Open Track 피칭 결과에 따라 상위 N개 팀에는 후속 멘토링 기회가 제공된다.

## 6. 최종 점검

- 타깃 고객의 지역, 역할과 사용 상황이 구체적인가
- 고객이 실제로 겪는 문제와 현재 해결 방법의 한계가 확인됐는가
- 실제 고객 접점을 통해 돈을 낼 이유를 검증했는가
- AI가 핵심 문제를 해결하는 과정이 프로덕트에서 작동하는가
- 기획안, 영상, 배포 제품과 IR 자료의 설명이 일치하는가
- 제출 형식과 발표 유의사항을 모두 지켰는가

# SEQRET 앱 화면 시안

| 순서 | 화면 | 역할 | 핵심 행동 |
| ---: | --- | --- | --- |
| 1 | 새 이사 만들기 | 소비자 | 일정·장소·촬영 공간 입력 |
| 2 | 60초 방 촬영 | 소비자 | 공간을 촬영하고 누락 구역 확인 |
| 3 | AI 짐 초안 검수 | 소비자 | 불확실한 항목만 확인·수정 |
| 4 | 이사업체 초대 | 소비자 | 선택한 업체에 역할 링크 전달 |
| 5 | 작업범위·견적 작성 | 업체 | 포함·제외 작업과 금액 제안 |
| 6 | 공동확인 카드 | 소비자 | 업체 제안 v3 확인 또는 수정 요청 |
| 7 | 작업 전 브리핑 | 현장기사 | 배차된 최신 승인본·체크리스트 확인과 체크인 |
| 8 | 현장 차이 보고 | 현장기사 | 승인본과 다른 사실을 증거로 보고 |
| 9 | 현장 변경 승인 | 소비자 | 변경 작업·사유·금액에 응답 |
| 10 | 완료·거래 기록 | 소비자 | 완료 자료 확인, 완료 결정 또는 문제 신고 |

시안은 390×844 모바일 화면을 기준으로 한 제품 흐름 참고 자료다. 소비자·현장기사 mobile 화면과 반응형 업체 web console을 기준으로 하며, 실제 route·상태·API 계약은 source와 backend OpenAPI를 따른다. AI 결과는 초안이며 가격·파손·책임을 자동 판단하지 않는다.

# 고객 진입 흐름 점검

## 결론

역할 선택부터 새 이사 또는 연결 코드 진입까지는 정상적으로 이어진다. 다만 연결 코드 사용 시 처음 입력한 고객 이름이 별도 안내 없이 연결된 이사의 서버 이름으로 바뀌는 문제가 남아 있다.

## 단계별 상태

1. 역할 선택 — 정상. 고객 선택 후 중복된 새 이사/연결 코드 분기 없이 이름 입력으로 이동한다.
2. 이름 입력 — 정상. 빈 값에서는 시작 버튼이 비활성화되고 이전 버튼으로 역할 선택에 돌아갈 수 있다.
3. 고객 홈 — 정상. 입력한 이름으로 인사하고 이사 시작 진입점이 한 곳만 노출된다.
4. 이사 시작 선택 — 정상. 새 이사와 연결 코드가 한 다이얼로그에서 분리된다.
5. 새 이사 — 대체로 정상. 일정 입력으로 이어진다. 첫 화면의 뒤로가기는 선택 다이얼로그가 아니라 고객 홈으로 돌아간다.
6. 연결 코드 — 정상. 코드 입력과 이전 동작이 명확하다.
7. 연결 완료 — 주의 필요. 입력한 이름이 서버의 고객 이름으로 조용히 교체되고, 성공 직후에는 내 이사 목록으로 이동해 이름 변경을 바로 알 수 없다.

## 우선순위

1. 연결 성공 전에 고객 이름을 조회할 수 있다면 `김서큐님의 이사를 연결할까요?` 확인 단계를 제공한다.
2. 사전 조회가 어렵다면 연결 성공 직후 `김서큐님의 이사를 불러왔어요` 안내를 표시한다.
3. 장기적으로 로그인/프로필 이름과 이사 계약의 고객 이름을 별도 필드로 관리한다.
4. 새 이사 첫 화면의 뒤로가기를 이사 시작 선택 다이얼로그로 되돌릴지 결정한다.

## 검증 범위

- 390×844 모바일 뷰포트
- 프로젝트 Mock API
- DOM 구조, 버튼 상태, 화면 전환, 콘솔 오류
- 스크린 리더 실제 사용과 색 대비 수치는 별도 검증하지 않음
